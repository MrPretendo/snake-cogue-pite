# Snake Cogue Pite

A holographic Snake roguelite. Pure web: HTML, CSS, JavaScript and Canvas 2D — no dependencies, no build. English by default, Spanish with L.

**Play:** https://mrpretendo.itch.io/snake-cogue-pite

**Run locally:** `node tools/serve.js 8090` and open http://localhost:8090 (ES modules need http, not file://).

A vibe-coded minigame, an extra from a bigger project; published because it turned out to be fun. Modify it, extract it, repackage it or continue it — the only ask is the appropriate credit.
